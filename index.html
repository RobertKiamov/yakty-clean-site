Инструкция владельцу

Если сайт «сломался» после правок

Этот сайт — обычный HTML/CSS/JS без React. Сниппеты вида <motion.div … className=…> (React/Tailwind/Framer Motion) вставлять в index.html НЕЛЬЗЯ: браузер их не понимает, страница и мобильная версия ломаются. Лечение: полностью заменить содержимое index.html на актуальную сборку (Ctrl+A → Delete → вставить → Ctrl+S) и обновить браузер Ctrl+F5. Папку проекта держите без пробелов и кириллицы: yakty-clean-site.

Формы заявок: решение владельца

Формы с сайта УБРАНЫ по решению владельца: конверсия идёт через телефон и мессенджер. Если позже понадобится своя форма — добавьте отдельный блок перед </main> и подключите свой обработчик; текущая сборка не содержит форм и не отправляет никаких данных пользователей, кроме согласованной аналитики.
